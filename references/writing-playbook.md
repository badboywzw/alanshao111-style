# 写作手册

## 短帖结构

这些是表达路径，不是需要逐字套用的口头禅。

| 路径 | 内容顺序 | 适用主题 |
|---|---|---|
| 具体反差 | 看起来的成果 → 看不见的动作 → 一句判断 | 自律、创作、积累 |
| 小动作开场 | 一个现在能做的动作 → 预期反馈 | 拖延、开始 |
| 时间差 | 眼前回报 → 延迟回报 → 选择 | 注意力、长期项目 |
| 算账 | 明确假设 → 简单计算 → 行为含义 | 时间分配、内容复用 |
| 轻微自嘲 | 一个普通人的窘境 → 认清问题 → 下一步 | 完美主义、表达焦虑 |

## 三种工作模式

**创作**：从主题找一个具体冲突，写成短帖。用户只要文案时不附创作过程。

**改写**：保留原文的事实、立场和对象；缩小到一个观点，删除铺垫，重排行距。不能为了反差把限定性结论改成绝对判断。

**批量**：先在内部给每条分配不同抓手，例如交付、反馈、注意力、成本、信任。不要只换开头或换一个表情。用户要选题时再展示选题表。

## 原创示例

以下为本项目编写的演示，不是 Alan 原帖。

### 主题：第一个作品

把第一版发出去。

没人看，也算拿到了第一条反馈。

### 主题：注意力

今天先留半小时。

手机够不着。

作品够得着。

### 主题：积累

日历会记住你忙过。

作品会让别人看见你做过。

今晚交一小段。

## 改写示例

输入：“我经常担心写得不好，所以一直在研究平台规则、收藏写作教程，结果两个月都没有发布任何内容。”

输出：

教程又存了十篇。

草稿还是零篇。

今天先把一句话写完，再打开收藏夹。

不额外添加“我运营八年”“我涨了九万粉”等原作者经历。

## 样本的使用限制

报告来自 2026-10-07 至 2026-10-23 的 194 条样本，覆盖特定播客与社群扩张期。字数、频率、互动和话题占比只是这段样本的记录，不是长期规律或当前账号数据。无需为了普通写稿抓取 X；当用户要求核验原帖或最新情况时再查证。
